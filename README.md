# NullDep

## Description

**NullDep** is a zero dependency command line network tool for Linux that can be used to:
* Display wireless interfaces
* Set the wireless interface mode, for example managed or monitor
* Scan the surrounding area for access points and their clients
* **And more to come!**

## Installation Guide

1. Clone the repository:
```bash
git clone https://github.com/lucatondeur/NullDep.git
cd NullDep
```
2. Build and install:
```bash
sudo pip install --break-system-packages .
```
